# GPO Values & Trade Calculator

Official Grand Piece Online (GPO) Trading Values, Tier List, and Trade Calculator web application.

## Features
- **Accurate In-Game Trading Values:** Real-time database of 213 in-game items, devil fruits, weapons, chests, accessories, and cosmetics.
- **Fair Trade Calculator:** Interactive calculation with Win / Fair / Lose verdict stamps, difference metrics, demand analysis, and shareable trade URLs.
- **Authentic GPO In-Game UI:** Dark charcoal translucent panels with sharp serrated/jagged edges, quest tracker badges, and Roblox/GPO gradient buttons.
- **Chests Economy:** Correct mathematical ratios (10x vs 1x) for Mythical, Legendary, and Rare fruit chests.
- **Comprehensive Item Browser:** Search by full name or abbreviation (ASE, CC, PWE, Mochi...), filter by category and tier.
- **Multi-Language Support:** Russian (RU) and English (EN) localization with persistent language memory.

## Run Locally
```bash
npm start
# or: node server.js
```
Open http://localhost:3000 in your browser.
